# 상세에 딸려 나오는 이미지 2장 (인스타 피드 1장 + 대표 이미지)

목차: 0. 언제·왜 · 1. 규격 · 2. 안전 여백 · 3. 문구 규칙 · 4. 심사 반려 잘 나는 표현 · 5. AI 표기 · 6. 결(look)별 차이 · 7. 인스타 캡션·해시태그 · 8. 만드는 순서와 결과물 · 9. 한계

> 2026-11-21 주누 지시로 2장만 만든다. 네이버 광고(디스플레이·메인·검색홈)·인스타 캐러셀·스토리는 뺐다. 다시 필요해지면 그때 규격부터 새로 확인한다.

---

## 0. 언제·왜

상세페이지를 다 만든 뒤 사용자가 원할 때만 만든다. 목적: **인스타에서 보고 넘어왔을 때, 몰 목록에서 썸네일을 눌렀을 때 "같은 가게"로 이어져 보이게.**
그래서 새로 디자인하지 않는다. 상세에 쓴 글·사진·색·폰트·구조선·사진 틀을 그대로 옮긴다(`assets/banner.html`이 상세 템플릿 4종의 CSS 언어를 그대로 갖고 있다).

## 1. 규격

확인: 2026-11.

| 파일(`data-name`) | 어디에 | 크기 | 형식 | 내용 |
|---|---|---|---|---|
| `insta_feed` | 인스타 피드 1장 (광고로 돌려도 같은 이미지) | 1080×1350 (4:5) | PNG | 후킹 + 상품명 + 상품 사진 하나 |
| `thumb_1000` | 스마트스토어·쿠팡·자사몰 대표 이미지 | 1000×1000 (1:1) | JPG | 흰 배경 + 상품 누끼만. 글자·합성·테두리·워터마크 금지 |

- 인스타 피드는 4:5(1080×1350)가 기본이다. 일반 게시물과 광고 둘 다 이 비율로 쓴다. 2025년부터 프로필 격자는 3:4로 잘려 보여서 가운데 약 1012×1350만 보인다(2항). 3:4(1080×1440)도 앱에서 올릴 수 있지만, 광고 지면에 따라 더 긴 이미지는 잘릴 수 있어서 4:5로 만든다.
  출처: https://www.linearity.io/blog/instagram-size-guide/ , https://www.oktopost.com/blog/instagram-grid-size-guide/ , https://www.inro.social/blog/instagram-post-size
- 대표 이미지는 몰마다 등록 가이드가 기준이다. 상품이 화면 대부분을 차지하고 흰 배경. `thumb_1000`은 상품 둘레를 80px 띄운다. 쿠팡은 대표 이미지에 글자·로고·합성을 넣으면 반려되니 이 판에는 아무것도 얹지 않는다.

## 2. 안전 여백

| 판 | 비워 둘 곳 | 이유 |
|---|---|---|
| 피드 1080×1350 | 좌우 34px (글자·상품명) | 프로필 격자 썸네일은 3:4로 가운데만 보인다. 템플릿 기본 여백이 80px라 보통 신경 쓸 일이 없다 |
| 대표 이미지 1000×1000 | 상품 둘레 80px | 몰 목록에서 모서리가 둥글게 잘리고, 찜·배지 아이콘이 얹힌다 |

`banner.html` 미리보기 위쪽 "안전 여백 가이드" 버튼으로 빨간 점선을 켜 본다(내보낼 땐 자동으로 꺼진다). `export_banners.py`가 피드 글자가 점선 밖으로 나갔는지 자동으로 본다.

## 3. 문구 규칙 (피드)

피드 문구는 **새로 짓지 않는다. 상세 문구를 가져와 줄이기만 한다.** 가져오는 곳: 상세 s-01 `.lead` 후킹 + `h1`(브랜드 + 상품명). 정보설득형은 s-01 스펙 띠 3칸도 그대로.

1. **한 장에 메시지 하나.** 후킹 + 상품명. 장점·후기까지 다 넣지 않는다 — 나머지는 캡션과 상세가 한다.
2. **상품명은 상세 h1과 같게.** 줄임말을 쓰면 상세에서 "이게 그건가?" 한다.
3. **핵심 반복 단어를 그대로.** 상세에서 정한 단어(`psychology.md` 반복 노출)를 피드·캡션 첫 줄에 같은 표현으로.
4. **광고로 돌릴 수 있게 사실만.** 과장·단정·최상급 없이. 숫자 주장은 각주를 달 자리가 없으니 피드 이미지에 넣지 않는다(캡션에서 각주와 함께).
5. **식품·화장품·건강식품 효능 금지는 상세와 똑같이** (`copywriting.md` 금지 표현).
6. **가격·할인·"무료배송"·"구매하세요"·가짜 버튼을 넣지 않는다.**
7. **글자 크기**: 본문 28px↑, 캡션·AI 표기 24px↑. 대비 4.5:1(큰 글씨 3:1). 이모지 금지 — 아이콘은 SVG.

대표 이미지에는 글자를 넣지 않는다.

## 4. 심사 반려 잘 나는 표현 → 바꾸는 법 (피드를 광고로 돌릴 때)

| 반려 잘 나는 것 | 왜 | 바꾸는 법 |
|---|---|---|
| "최고·1위·No.1·유일·최초" (근거 없이) | 객관 근거 없는 최상급 | 빼고 사실로: "27년 같은 자리에서" |
| "100%·무조건·확실히·완벽" | 보증 표현 | 실제 조건: "받으신 날부터 14일 안 교환" |
| "○○에 좋은·면역·다이어트·디톡스·혈압" (식품) | 일반식품 효능 표시 | 감각·장면: "뚜껑 열기 전부터 고소한 냄새" |
| "재생·치료·염증·미백·주름 개선" (화장품, 기능성 심사 없이) | 의약품 오인 | "결 정돈", "촉촉하게" + 실제 사용감 |
| "아직도 ○○ 쓰세요?" / "당신의 뱃살" | 조롱·개인 특성 단정(메타 광고 정책은 건강·신체·재정 상태를 "당신은 ~하죠"로 단정하는 문구를 막는다) | 상황으로: "10분만 돌려도 손목이 시큰할 때" |
| 비포·애프터 사진, 신체 일부 확대 | 체중·피부 전후 비교에 엄격 | 쓰지 않는다. 사용 장면 사진으로 |
| 할인율·"오늘만"·"품절 임박" | 근거·기간 표기 필요, 가짜 긴급성은 기만 | 넣지 않는다 |
| 이미지 속 가짜 버튼·재생 아이콘·알림 모양 | 클릭 유도 기만 | 넣지 않는다 |
| 의사·약사·흰 가운 AI 인물 (식품·건기식·화장품) | 2026-11-27 시행 금지 — AI 표시해도 안 됨 | 쓰지 않는다 (`research.md` 제도 3) |

애매하면 상세와 같은 기준: 단어가 아니라 전체 인상으로 판단된다. 확신이 없으면 `5_광고문구.md`에 `[심사 확인 필요]`를 남긴다.
건강식품·다이어트·탈모·언더웨어는 메타 광고도 심사가 까다롭다 — 광고로 돌릴 거면 한 번 알리고, 신체 노출·전후 비교 사진은 넣지 않는다.

## 5. AI 표기

- AI로 만든 연출컷이 들어간 피드에만 `.ai` "연출 이미지(AI 활용)"를 남긴다. 실물 사진·실물 누끼(배경 제거·색 보정만)엔 달지 않는다.
- 메타는 사실적인 AI 이미지에 "AI 정보" 라벨을 붙인다(광고 관리자에서 생성형 AI 사용 여부를 묻는 칸이 있으면 사실대로 체크). AI 기본법 표시 의무는 도구 제공사 몫이라 셀러에겐 법적 의무가 아니다(`research.md` 제도 1).
- **대표 이미지(`thumb_1000`)는 실물 사진 누끼로만** 만든다. AI로 그린 상품을 대표 이미지로 쓰지 않는다 — 받아 본 물건이 다르면 반품이 온다.
- 실사형은 사진 캡션이 "실물 촬영 · 날짜 · 장소"라서, AI 컷을 쓰면 그 캡션을 "연출 이미지(AI 활용)"로 바꾼다.

## 6. 결(look)별로 피드가 어떻게 다른가

`data-look`은 상세 템플릿과 같은 값으로 둔다. 다른 결의 장치를 섞지 않는다(`design.md` 9항). 대표 이미지는 결과 상관없이 흰 배경 + 누끼로 같다.

| | 연출형 `scene` | 정보설득형 `spec` | 매거진형 `magazine` | 실사형 `maker` |
|---|---|---|---|---|
| 바탕 | 질감(`images/tex_a.jpg`) | 흰 바탕 | 종이색 한 가지 | 따뜻한 종이색 |
| 그림 | 주인공 누끼 하나 크게, 살짝 기울임 + 그림자 | 누끼를 회색 받침(`.stage`) 위에 + 스펙 띠 3칸 | 풀블리드 큰 사진 | 흰 테(`.mat`) 실사 + "실물 촬영 · 날짜 · 장소" |
| 글자 | 굵은 고딕 + 앞부분 가는 글씨, 밑줄 `.u` | 굵은 고딕, 형광펜 `.u` | 명조 크고 가늘게, 가는 밑줄 | 굵은 고딕, 상품명 강조색 글자 |

## 7. 인스타 캡션·해시태그 (`5_광고문구.md`에)

- **첫 줄이 후킹.** 피드에선 앞 한두 줄(대략 125자 안팎)만 보이고 나머지는 "더 보기"로 접힌다. 첫 줄 = 상세 `.lead` 후킹(피드 이미지와 같은 말).
- 둘째 줄부터: 상품명(h1 그대로) → 장점 한두 줄(상세 5번) → 받는 법 한 줄("프로필 링크에서 보실 수 있어요"). 짧은 줄 4~6개, 빈 줄로 나눈다.
- 가격·할인은 넣지 않는다. 숫자 주장은 각주와 함께("리뷰 3,812개 · 2026.11 스마트스토어 기준").
- **해시태그 5~10개**, 캡션 맨 끝에. 상품명 1 + 카테고리 2~3 + 쓰는 장면 2~3 + 지역·가게 1~2. 효능·금지 표현 태그(#다이어트 #면역력)는 쓰지 않는다.
- 이모지는 문장 안 1~2개까지(발랄 결일 때만), 줄머리 아이콘처럼 쓰지 않는다.
- 광고로 돌릴 땐 캡션 = 광고 "기본 문구", 제목란 = 상품명, 링크 = 상세(스마트스토어) 주소.

## 8. 만드는 순서와 결과물

1. 상세 완성 후 묻는다(SKILL.md "피드·썸네일 이미지").
2. `assets/banner.html`을 `상세페이지_[상품명]/5_배너.html`로 복사 → 루트 `data-look/theme/font/preset`을 상세 `.page`와 같게, 상세에서 바꾼 색 변수가 있으면 붙인다.
3. `{{자리}}`를 상세 문구로 채운다(3항). AI 컷이 없으면 `.ai`를 지운다.
4. 누끼가 없으면 상세 첫 화면 실물 사진에서 배경을 지운다(`image-guide.md` 누끼 — 힉스필드 `remove_background` 등). 대표 이미지는 실물 누끼로만.
5. `python assets/export_banners.py 5_배너.html 5_배너/` → PNG/JPG + 점검 보고(`_export_report.json`). "확인할 것"을 한 번에 고치고 한 번 더 돌린 뒤 끝. 질감·사진 위 글자는 눈으로 한 번 본다.
6. `5_광고문구.md` 작성: 인스타 캡션 + 해시태그 5~10개 + 심사 체크(바꾼 표현과 이유, `[심사 확인 필요]`).

```
상세페이지_[상품명]/
  5_배너.html            ← 채운 원본 (고치면 다시 내보낸다)
  5_배너/
    insta_feed.png  thumb_1000.jpg  _export_report.json
  5_광고문구.md
```

**export 의존성:** `pip install playwright pillow`. Windows는 Edge가 있어서 브라우저 설치가 필요 없다(없으면 `python -m playwright install chromium`). 옵션: `--look/--theme/--font/--preset`(결 바꿔 보기), `--only insta_feed`, `--suffix _b`(안 2개 비교), `--no-check`.

## 9. 한계

- 규격은 2026-11 정리 기준이다. 인스타 격자 비율은 최근에 바뀐 적이 있으니, 올릴 때 미리보기에서 잘림만 한 번 본다.
- 폰트는 CDN에서 받는다. 인터넷이 끊긴 PC에선 시스템 글꼴로 찍히니 그때는 다시 내보낸다.
- 연출형 질감(`tex_a`)·누끼가 없으면 단색 바탕·점선 자리로 찍힌다. 재료 만드는 법은 `image-guide.md`.
- 캐러셀·스토리·릴스·네이버 광고는 만들지 않는다.
