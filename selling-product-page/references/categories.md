# 카테고리별 변형 (15개)

`structure.md`의 공통 12단 구조를 기본으로 두고, 상품 카테고리에 맞춰 아래 표대로 바꾼다.
Q1 답변을 보고 아래 15개 중 하나를 고른다. 애매하면 가장 가까운 것 + "그 외" 규칙을 섞는다.

**두 카테고리에 걸칠 때 (2026-11-21) — 표기와 결을 따로 정한다.**
- **법적 필수 표기·금지 표현 = 법이 보는 품목 기준.** 전기로 움직이면(충전·콘센트) 가전디지털의 KC 전기용품 안전인증·정격·A/S 표기, 입에 닿는 식기·용기면 주방의 식품용 기구 표기, 피부에 바르면 화장품 표기. 둘 다 해당하면 **둘 다** 넣는다.
- **섹션 변형·디자인 결 = 손님이 비교하는 매대 기준.** 손님이 이 상품을 어느 진열대에서 다른 상품과 견주는지로 고르고, 그래도 애매하면 Q9-2 답(①전문가 → 가전 결, ②장인 → 주방·생활 결 등)으로 정한다.
- 예: 무선 핸디 블렌더 = 표기는 가전디지털(KC 전기용품·충전 사양·A/S) + 식품 접촉 부품(컵·날) 재질 표기, 결은 주방 또는 가전 중 Q9-2로. 기획안 맨 위에 "카테고리: 표기 ○○ / 결 ○○ (이유)" 한 줄.

각 카테고리마다 세 가지를 적어뒀다:
- **손님 심리** — 이 카테고리 손님이 페이지에서 진짜 궁금한 것 한 줄
- **섹션 변형** — 공통 구조에서 바뀌는 섹션만
- **필수 표기 / 금지** — 법적으로 꼭 넣을 것, 쓰면 안 되는 말

목차: 1 패션의류/잡화 · 2 뷰티 · 3 출산/유아동 · 4 식품 · 5 주방용품 · 6 생활용품 · 7 홈인테리어 · 8 가전디지털 · 9 스포츠/레저 · 10 자동차용품 · 11 도서/음반/DVD · 12 완구/취미 · 13 문구/오피스 · 14 반려동물용품 · 15 헬스/건강식품

## 히어로 배너 가이드 (첫 화면 1번의 유형)

공통 원칙: **상품이 눈에 잘 들어와야 한다.** 텍스트 배치는 카테고리에 따라 세 유형 중 하나.

- **A 프로덕트형** — 상품(또는 핵심 숫자)이 또렷한 주인공. 깨끗한 배경, 카피는 **HTML**로 이미지 빈 공간이나 이미지 위 제목 자리. AI 텍스트 생성 금지(숫자·인증·기능성 문구는 정확해야 하고 자주 고친다).
- **B 무드형 (아트 배너)** — 연출된 공간·감성 컷 자체가 셀링포인트인, "예뻐야 하는" 카테고리. **텍스트까지 이미지에 디자인해도 된다**(AI 텍스트 생성 OK — 짧은 한글 단어 위주, 깨지면 재생성, 두 번 깨지면 HTML 합성). 타이포가 디자인 요소가 되는 유형. 페이지당 이런 배너는 히어로 포함 1~2개까지.
- **(2026-11-04 기본)** 세 유형 모두 `.scene` 연출로 만드는 게 먼저다 — 질감 바탕 위에 상품·결과물·재료 누끼를 배치하고 굵은 제목을 빈 자리에 앉힌다(`design.md` 0항). 아래 A/B/C는 "주인공이 뭐냐"를 고르는 기준으로 쓴다. 어두운 스크림은 다크 테마(스포츠)에서만.
- **C 장면형** — 사용·결과·욕구 장면 풀블리드 + 스크림 + **HTML 오버레이**. 상품이 장면 안에서 잘 보이는 위치에 있어야 하고, 글자가 상품·먹음직한 부분을 가리면 `.bottom`으로 내린다.

| 카테고리 | 유형 | 히어로 재정의 |
|---|---|---|
| 1 패션 | **B** | 전신 착용 무드컷. 글자 최소 — 브랜드/시즌 워딩 정도는 이미지에 디자인 OK |
| 2 뷰티 | **A** (용기 예쁘면 B) | 제형·질감 클로즈업 + 화제성 숫자("1위"·"○만 개")는 표시광고법 때문에 반드시 HTML |
| 3 출산/유아동 | **C** | 아이가 쓰는 따뜻한 장면 + "○개월부터" 오버레이. 인증 배지는 HTML로 작게 |
| 4 식품 | **C** | 식욕 자극 컷이 전부 — 스크림 최소, 글자 최소, 김·과즙 가리지 않게 `.bottom` 기본 |
| 5 주방용품 | **C** | 요리하는 손 + 결과 한 줄("눌어붙음 0") 오버레이 |
| 6 생활용품 | **C** | 쓰는 순간 + 결과 한 줄 오버레이 |
| 7 홈인테리어 | **B** | 오늘의집식 공간 연출컷. 감성 타이포까지 이미지에 디자인 OK |
| 8 가전디지털 | **A** | 제품 히어로샷 + 핵심 스펙 숫자 하나 — 숫자는 HTML |
| 9 스포츠/레저 | **C** | 현장 액션컷 + 진한 스크림 위 오버레이(역동적 배경이라 대비 필수) |
| 10 자동차용품 | **C** | 차 안 설치컷 + 결과 한 줄("흔들림 0") 오버레이 |
| 11 도서/음반 | **A** | 표지가 주인공(표지 자체가 디자인된 텍스트) + 한 줄 카피는 HTML |
| 12 완구/취미 | **C** (취미 완성작은 B) | 아이가 노는 장면 + 대상 연령 오버레이 |
| 13 문구/오피스 | **B** | 책상 위 감성컷. 캘리그래피·레터링을 이미지에 디자인 OK |
| 14 반려동물 | **C** | 반려동물이 실제 쓰는/먹는 장면 + 한 줄 오버레이 |
| 15 헬스/건강식품 | **A** | 기대 변화 문구가 주인공 — 기능성 문구는 식약처 인정 문구 그대로여야 하니 **무조건 HTML**, AI 텍스트 절대 금지 |

## 1. 👗 패션의류 / 잡화

**손님 심리:** "나한테 어울릴까? 사이즈 맞을까? 사진이랑 똑같을까?"

| 섹션 | 변형 |
|---|---|
| 1 첫 화면 | **착용 분위기 컷** (전신, 자연광). 글자 최소. 상품 단독샷은 첫 화면에 안 쓴다 |
| 2 신뢰 | 판매량, 재구매율, 리뷰수, "실측 사이즈 제공" |
| 3 공감 | "온라인으로 옷 샀다가 사이즈 실패", "세탁 한 번에 늘어남", "사진이랑 색이 달라서" |
| 5 장점 | 핏·소재·활용도. "폴리 100%" → "구김 없이 캐리어에 넣어도 돼요" |
| 6 증거 | **색상별 실물 사진**(스튜디오 조명 X, 자연광), 세탁 전후, 신축 테스트 |
| 7 사용 장면 | **착용샷 3컷 이상** — 모델 키·몸무게·착용 사이즈 명시. 코디 2~3가지(출근/데이트/캐주얼) |
| 8 후기 | 키·몸무게·구매 사이즈 표시된 후기 우선 |
| 9 상세 정보 | **사이즈표(cm, 실측)**, 소재 혼용률, 세탁법, 원산지, 모델 사이즈, 신축성/비침/두께/안감 5단계 표 |
| 10 FAQ | "165에 55면 M? L?", "비침 있나요?", "세탁기 돼요?" |

**필수 표기:** 소재 혼용률, 치수, 제조국, 세탁 방법, 제조자/수입자, 품질보증 기준.
**금지:** "정품"(브랜드 라이선스 없이), 연예인 착용 사진 무단 사용, 색상 과보정.

## 2. 💄 뷰티

**손님 심리:** "내 피부에도 효과 있을까? 자극은 없을까? 진짜 검증된 거야?"

올리브영 카테고리 1위들의 공통 **7단계**: 후킹 → 사회적 증거 → 차별 기술 → 수치 근거 → 기술 설명 → 안전/인증 → 사용법·효과.

| 섹션 | 변형 |
|---|---|
| 1 첫 화면 | **"1위", "품절대란", "○○만 개 판매"** 화제성 + 카테고리 재정의("메이크업이 아니라 슬로에이징"). 1위는 플랫폼·카테고리·기간 명시 필수 |
| 2 신뢰 | 누적 판매량, 만족도 %, 피부 전문가 추천, 올리브영·화해 랭킹 |
| 5 장점 | 성분명 말고 **피부가 느끼는 결과**. "BHA 0.5%" → "코 옆 거뭇한 거 닦아내요" |
| 6 증거 | **숫자 하나 크게**: "-4.9°C", "수분 425배", "24시간 지속". 시험기관·n수·기간 작게 병기. 비포/애프터는 "개인차 있음" 필수 |
| 7 사용 장면 | **사용 순서 1-2-3** + 피부타입별 + 아침/저녁 루틴 위치 |
| 8 후기 | 피부타입·나이 표시("건성, 30대") |
| 9 상세 정보 | 전성분, 용량, 사용기한, 제조·책임판매업자, 기능성 심사 여부 |
| 10 추천 | "□ 모공 고민 □ 민감성 □ 비건 찾는 분" + 비건·더마테스트·무향 배지 |

**필수 표기:** 전성분, 용량, 사용기한, 제조업자·책임판매업자, 사용 시 주의사항.
**금지:** "치료", "재생", "주름 제거"(기능성 심사 없이), "피부과 수준", 의약품 오인 표현.

## 3. 🍼 출산 / 유아동

**손님 심리:** "우리 아이한테 안전해? 다른 엄마들도 써? 몇 개월부터 돼?"
가장 신뢰에 민감한 카테고리. 과장 하나면 커뮤니티에서 바로 퍼진다.

| 섹션 | 변형 |
|---|---|
| 1 첫 화면 | 아이가 실제로 쓰는 따뜻한 장면 + "○개월부터". 안전 인증 배지를 첫 화면에 작게 |
| 2 신뢰 | **KC 어린이제품 인증, 무독성·유해물질 검사, 소아과/육아 전문가, 맘카페 후기 수** |
| 3 공감 | "밤에 몇 번씩 깨서", "이유식 거부", "기저귀 발진" — 부모의 피로한 순간 |
| 5 장점 | 안전 → 편의 → 아이 반응 순서. "BPA free" → "열탕 소독 백 번 해도 안심" |
| 6 증거 | **시험성적서 캡처(기관명·항목)**, 소재 단면, 내구성 테스트 |
| 7 사용 장면 | **월령별 사용법** (3개월/6개월/12개월), 세척·소독법 |
| 8 후기 | 아이 개월수 표시된 후기, 사진 후기 |
| 9 상세 정보 | 대상 연령, 소재, 사이즈/무게, 세척법, KC 인증번호, 제조국 |
| 10 FAQ | "신생아도 돼요?", "식기세척기 돼요?", "소독 어떻게?" |

**필수 표기:** KC 어린이제품 안전인증(해당 시), 사용 연령, 경고 문구(질식 위험 등), 제조자.
**금지:** "100% 안전", "아토피 완화", "두뇌 발달"(근거 없이), 의료 효과.

## 4. 🍱 식품 (농수산물·간편식·간식·음료)

**손님 심리:** "맛있을까? 신선할까? 애들 먹여도 돼?"
저관여·탐색형 — "검색해서" 안 사고 "보다가" 산다. 첫 화면이 전부다.

| 섹션 | 변형 |
|---|---|
| 1 첫 화면 | **식욕 자극 사진** — 김, 단면, 과즙, 구워지는 장면. 글자 최소. 영상/GIF 효과 큼(쿠팡은 GIF 불가→영상 기능) |
| 3 공감 | "마트 과일 복불복", "저녁 뭐 먹지", "애 간식 고민" |
| 5 장점 | 재료·영양 나열 X. **맛·식감·향·간편함**. "당도 13브릭스"보다 "한 입에 과즙이 턱까지" |
| 6 증거 | 당도 측정, HACCP/무항생제/유기농 인증, 산지·수확·제조 과정 사진 |
| 7 사용 장면 | **조리법·활용 레시피 2~3개** (전자레인지 3분, 에어프라이어, 토핑). 식품은 이 섹션이 구매를 결정한다 |
| 9 상세 정보 | 원재료명·함량, **알레르기 유발물질**, 영양정보, 유통기한, 보관법, 제조원·원산지 |
| 11 구매 | 신선 포장(아이스팩·스티로폼) 사진, 배송 요일 안내 |

**필수 표기:** 식품유형, 원재료·함량, 알레르기, 영양정보, 유통(소비)기한, 보관법, 제조원, 원산지.
**금지:** 질병명+효과("당뇨에 좋은", "면역력 강화"), 일반식품을 건강기능식품처럼 보이게 하는 표현, "다이어트".

## 5. 🍳 주방용품 (조리도구·식기·보관용기·주방가전 소품)

**손님 심리:** "지금 쓰는 거보다 뭐가 나은데? 설거지 편해? 오래 가?"

| 섹션 | 변형 |
|---|---|
| 1 첫 화면 | **요리하는 손 + 결과 한 줄** ("눌어붙음 0, 물로 쓱"). 식기면 음식 담긴 모습 |
| 3 공감 | 눌어붙은 팬, 눅눅한 수세미, 뚜껑 안 맞는 반찬통 — **비포 사진이 설득의 80%** |
| 4 해결 | 애프터 사진. 3번과 같은 앵글 |
| 5 장점 | 소재·구조 → 그래서 편한 점. "세라믹 코팅" → "기름 안 둘러도 안 붙어요" |
| 6 증거 | **비교표**(기존 vs 우리: 세척·냄새·내구성·열전도 O/X), 내구성 테스트, **식품접촉 안전 검사** |
| 7 사용 장면 | 인덕션/가스 호환, 식기세척기·전자레인지·오븐 가능 여부 아이콘, 여러 요리 장면 |
| 9 상세 정보 | 사이즈(mm)·용량(ml)·무게, 소재, 호환 열원, 내열온도, 세척법 |
| 10 FAQ | "인덕션 돼요?", "식기세척기?", "코팅 벗겨져요?" |

**필수 표기:** 재질, 식품접촉 적합(식약처 기준), 내열온도, 제조국, 사용상 주의.
