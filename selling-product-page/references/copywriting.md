# 문구 쓰는 법 + 금지 표현

## 문구 원칙 5가지

1. **손님 말로 쓴다.** 판매자가 자랑하고 싶은 것 ≠ 손님이 궁금한 것. 모든 문장을 "그래서 나한테 뭐가 좋은데?"로 검사한다.
   - X "프리미엄 항균 실리콘 소재 적용" → O "일주일 써도 냄새 안 나요"
2. **장면으로 쓴다.** 추상어("편리한", "건강한", "고품질")는 아무 그림도 안 떠오른다.
   - X "바쁜 아침에 편리해요" → O "출근 전 3분, 전자레인지 돌리는 동안 양치 끝"
3. **짧게.** 헤드카피 15자 안팎, 설명 2줄. 모바일에서 한 줄이 넘어가면 안 읽는다.
4. **숫자는 구체적으로.** "많은 분들이" → "누적 12,480분이". 단, 진짜 숫자만.
5. **한 섹션에 메시지 하나.** 두 개 말하면 둘 다 기억 못 한다.

## 헤드카피 공식 (첫 화면·섹션 제목용)

> **첫 화면 제일 큰 글씨는 상품 이름으로 쓴다.** 아래 공식으로 뽑은 후킹 문구는 그 위 작은 글씨(`.lead`)에 올린다.
> 큰 글씨 = 상품 이름 / 작은 윗글씨 = 후킹. 순서를 바꾸면 손님이 무슨 상품인지 모른 채 스크롤한다.
> 예: 작은 글씨 "여덟 시간을 앉아도 등이 안 젖는" → 큰 글씨 "브룩스 **매쉬 체어**"

| 공식 | 틀 | 예시 |
|---|---|---|
| 결과 제시 | [행동] 해보세요. [결과]예요. | "설거지 끝나고 손 냄새 맡아보세요. 아무 냄새도 안 나요." |
| 숫자 | [숫자] + [의미] | "재구매율 78%" / "1초에 1개씩 팔리는" |
| 재정의 | [기존 카테고리]가 아니라 [새 정의]입니다 | "수세미가 아니라 손 보호대입니다" |
| 상황 | [시간/상황], [해결] | "퇴근하고 10분, 이걸로 저녁 끝" |
| 질문 | [고민]하세요? | "한 달에 수세미만 몇 개 사세요?" |
| 대비 | [전] → [후] | "3일 만에 눅눅 → 한 달째 보송" |
| 약속 | [조건]이면 [보상] | "맛없으면 100% 환불" |

## 섹션별 문구 톤

| 섹션 | 톤 | 길이 |
|---|---|---|
| 1 첫 화면 | 자신 있게, 짧게 | 1줄 |
| 3 공감 | 손님 편에서, 살짝 답답하게 | 장면당 1~2줄 |
| 4 해결 | 밝게, 시원하게 | 1줄 |
| 5 장점 | 친절하게 설명 | 제목 1줄 + 설명 2줄 |
| 6 증거 | 담담하게, 숫자 중심 | 숫자 + 출처 |
| 8 후기 | 손님 말투 그대로 | 핵심 문장만 |
| 11 구매 유도 | 밀어주되 협박 X | 구성 + 욕구 장면 문구 1줄 (가격 X·버튼 X — 요청 시에만) |

## 분위기(Q9-2)별 말투

- **깔끔·믿음직:** 존댓말, 단정. "~합니다", "~입니다". 느낌표 최소.
- **따뜻·정겨운:** "~해요", "~거든요". 만든 사람 이야기 한 줄 넣기. ("제가 직접 담근")
- **고급:** 짧은 명사형. "하루의 마무리." "손끝에서 시작되는." 느낌표 금지.
- **발랄·트렌디:** "~했잖아요", "이거 하나면 끝". 이모지 1~2개 허용(문장 안에서만 — 아이콘 대신 쓰지 않는다).
- **알뜰한 선택 (Q9-2 ⑤, 2026-11-21):** "~예요" 단정형, 숫자·비교를 문장 맨 앞에("2병이면 한 달 반, 따로 살 일 없어요"). 느낌표는 한 페이지에 한두 개. 싸다는 말 대신 "따져보면 이득"인 근거(용량·횟수·구성)를 보여준다.

## 금지 표현 (표시광고법 — 과태료·판매중지 사유)

사용자가 Q3·Q10에서 이런 말을 요청해도 **안전한 표현으로 바꾸고 이유를 한 줄로** 알려준다.
("'면역력 강화'는 건강기능식품 인증 없이 쓰면 식약처에서 걸려요. '매일 챙기는 건강 습관'으로 바꿨어요.")

### 모든 카테고리 공통
| 금지 | 왜 | 대신 |
|---|---|---|
| "최고", "최초", "1위", "No.1", "유일" (근거 없이) | 객관적 증빙(수상·공인 통계) 없으면 부당광고 | "누적 ○만 개", "평점 4.8", "[플랫폼] [카테고리] [기간] 1위" (근거 명시) |
| "100% 효과", "확실히", "무조건" | 보증 불가 | "대부분의 고객이", "○%가 재구매" |
| 가짜 후기, 가짜 "품절 임박", 가짜 타이머 | 기만 광고 | 진짜 수치만. 없으면 안 쓴다. |
| 경쟁사 비방·직접 지명 비교 | 비교광고 규정 | 남의 상품명 금지. "일반 제품 대비"도 근거(시험·공개 자료)가 있을 때만 — 없으면 "고르는 기준" 표(`.criteria`: 기준 / 확인할 것 / 이 상품은) |

### 식품 (일반식품·건강기능식품)
| 금지 | 대신 |
|---|---|
| 질병명 + 효과: "당뇨에 좋은", "암 예방", "혈압 낮춰", "관절염에" | 건강기능식품이면 **식약처 인정 기능성 문구 그대로** ("혈행 개선에 도움을 줄 수 있음"). 일반식품은 효능 언급 자체를 안 한다. |
| "다이어트", "살 빠지는", "디톡스", "면역력 강화" (일반식품) | "가볍게 즐기는", "매일의 건강 습관" |
| "천연", "무첨가" (일부만 해당될 때) | 정확히: "합성보존료 무첨가" |
| "무설탕", "무당" | 식품 100g(음료 100ml)당 당류 0.5g 미만일 때만 쓸 수 있는 영양강조 표시다(식품등의 표시기준). **말린 과일·과일청·꿀은 원재료 자체에 당이 있어 사실상 못 쓴다.** → "원재료 감귤 100%", "감귤만 썰어 말렸어요", "설탕을 따로 넣지 않았어요"(사실일 때) |
| "무가당" | 당류나 당류를 대신하는 원료(시럽·농축과즙·꿀 등)를 **전혀 넣지 않았을 때만**. 원재료 배합표·제조 기록을 근거로 보관한다. 애매하면 위 "원재료 ○○ 100%" 식으로 |
| 의사·약사 추천 (일반식품) | 삭제 |

건강기능식품은 반드시 "본 제품은 질병의 예방 및 치료를 위한 의약품이 아닙니다" 고지.

### 화장품
| 금지 | 대신 |
|---|---|
| "치료", "재생", "회복", "염증 완화", "여드름 치료" | "진정", "케어", "결 정돈" |
| "주름 개선", "미백" (기능성 심사 없이) | 심사받은 제품만. 아니면 "탄력 케어", "톤 케어" |
| "피부과 처방", "의약품 수준" | 삭제 |
| 비포/애프터 (개인차 문구 없이) | 반드시 "개인에 따라 차이가 있을 수 있습니다" 병기, 시험 조건 표기 |
| "모든 피부에 안전" | "피부 자극 테스트 완료 (○○기관, n=30)" |

### 생활용품
| 금지 | 대신 |
|---|---|
| "99.9% 살균·항균" (시험성적서 없이) | 시험 있으면 기관명·조건 병기. 없으면 "위생적으로" |
| "반영구", "평생", "절대 안 망가짐" | "○년 보증", "1만 회 테스트 통과" |
| "친환경", "에코" (인증 없이) | 구체적으로: "재활용 가능 소재", "플라스틱 ○% 감축" |

### 애매하면
단어 하나가 아니라 **전체 맥락**으로 판단된다. 금지어를 안 써도 "병이 낫는다"는 인상을 주면 걸린다.
확신 없으면 기획안에 `⚠️ 표현 확인 필요` 표시를 남기고 사용자에게 "이 문구는 전문가 확인이 필요할 수 있어요"라고 알린다.
