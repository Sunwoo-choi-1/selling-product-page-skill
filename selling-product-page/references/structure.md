# 잘 팔리는 상세페이지 12단 구조

한국 쇼핑몰 상위 판매 상세페이지(올리브영 카테고리 1위, 쿠팡 어워즈 베스트리뷰, 스마트스토어 상위 셀러)를 분석해서 뽑은 공통 뼈대다.
손님은 모바일로, 엄지로 쓱쓱 넘기면서 본다. 그래서 **첫 3초 안에 붙잡고 → 믿게 하고 → "내 얘기네" 싶게 하고 → 숫자로 증명하고 → 지금 사게 한다**는 흐름이 전부다.

섹션은 12개지만 꼭 12개를 다 채울 필요는 없다. 숫자·시험 근거가 없으면 6번을 "고르는 기준" 표(`.criteria`)로 세우거나 빼고, 후기가 없으면 후기 블록을 지우고 "맞는 분 / 안 맞는 분"(`.fitcheck`, 템플릿마다 8번 또는 10번 자리)을 두는 식으로 유연하게.
단, **1·3·5·11번은 절대 빼지 않는다.** 이 넷이 없는 페이지는 안 팔린다.

---

## 공통 구조

### 1. 첫 화면 (후킹) — 3초 안에 붙잡기
- **역할:** 스크롤을 내리게 만드는 것. 설명하는 자리가 아니다.
- **구성:** 작은 글씨 후킹 한 줄(`.lead`) → **큰 글씨 상품 이름**(`h1`) → 설명 2줄 → 상품이 가장 예쁘게 나온 사진 한 장. 끝. 아래 헤드카피 공식은 큰 글씨가 아니라 작은 윗글씨(`.lead`)에 쓴다 (2026-11-07 규칙, SKILL.md). 식품·뷰티처럼 "보다가 사는" 카테고리는 후킹에 신뢰 근거보다 감각 하나를 먼저(`psychology.md` 감각 언어).
- **반전형 상품(변신·분리·비포/애프터가 셀링포인트)은 사진 두 장을 나란히:** "평소 모습 ↔ 쓰는 모습". 카피를 안 읽어도 상품이 이해된다. 이때 구성 요약 카드(구성·교환반품·배송)를 첫 화면 바로 아래 붙인다 — 가격은 없이.
- **헤드카피 공식(하나 고르기):**
  - 결과 제시형: "설거지 끝나고 손 냄새 맡아보세요. 아무 냄새도 안 나요."
  - 숫자형: "누적 12만 개 판매" / "재구매율 78%"
  - 재정의형: "수세미가 아니라, 손 보호대입니다" (카테고리를 새로 정의 — 올리브영 1위들이 즐겨 쓰는 방식)
  - 상황형: "퇴근하고 10분, 이걸로 저녁 끝"
- **하지 말 것:** 브랜드 로고만 덩그러니, 후킹 없이 상품명만 적기, 문장 3줄 이상.
- 쿠팡 기준 "첫 이미지에 '무료배송·오늘출발' 같은 키워드 넣었더니 전환 1.8배"라는 셀러 사례가 있다. 배송 장점이 있으면 여기 작은 배지로.

### 2. 믿을 근거 배지 (신뢰 한 줄)
- **역할:** "아, 많이들 샀구나 / 검증됐구나" 한 번에 보여주기.
- **구성:** 아이콘 3~4개 가로 배열. 판매량 · 평점/리뷰수 · 인증/수상 · 경력(○년) · 방송 중 있는 것만.
- **근거가 하나도 없을 때:** "직접 만듭니다 / 100% 국내산 / 불만족 시 환불" 같은 **약속**으로 대체. 거짓 숫자는 절대 안 된다.

### 3. 공감 (손님의 고민 장면)
- **역할:** "어, 이거 내 얘긴데" 하게 만들기. Q4·Q5 답변이 여기 들어간다.
- **구성:** 고민 장면 2~3개를 **구체적인 순간**으로. 추상어 금지.
  - 나쁨: "불편하셨죠?"
  - 좋음: "수세미 3일 쓰면 눅눅해지고 냄새나서 또 버리고… 한 달에 수세미만 몇 개 사세요?"
- **이미지:** 고민 상황을 보여주는 **밝은** 생활 장면을 원형 틀에, 고민 문구는 말풍선에(`.ask`). 어두운 딤 금지 — 답답함은 문구가 만든다. 과장된 연기 X.

### 4. 해결 선언
- **역할:** 긴장 풀어주기. "그래서 이렇게 만들었습니다."
- **구성:** 한 문장 선언 + 상품 사진(밝은 톤). 3번과 톤을 확 바꿔서 대비를 만든다.
- 예: "그래서 저희는 아예 '마르는 소재'로 만들었어요."

### 5. 핵심 장점 3가지
- **역할:** 사야 하는 이유. Q3 답변을 **손님 이득**으로 번역해서 넣는다.
- **구성:** 장점 3개 (최대 4개). 각각 = 제목(이득) + 설명 2줄 + 이미지 1장.
- **번역 공식:** [기능] → [그래서 손님한테 뭐가 좋은지]
  - 기능: "항균 실리콘 소재" → 이득: "일주일 써도 냄새 안 나요"
  - 기능: "당도 13브릭스" → 이득: "애들이 설탕 안 찍고도 먹어요"
- 상위 상세페이지는 특징을 3개 이내로 압축한다. 5개 넘으면 손님이 지친다 — 나머지는 9번(상세 정보)으로 보낸다.

### 6. 증거 (숫자·비교·시험)
- **역할:** 5번이 "진짜"라는 걸 보여주기.
- **구성 (있는 것만):**
  - 비교표: 일반 제품 vs 우리 제품 (3~5항목, O/X 또는 숫자) — **근거(시험·공개 자료)가 있을 때만.** 남의 칸을 근거 없이 채우면 비방·부당 비교 소지(`psychology.md` "하지 말 것")
  - 근거가 없으면 **"고르는 기준" 표 `.criteria`** (열: 고르는 기준 / 확인할 것 / 이 상품은). "이 네 가지만 보세요" 식으로 손님이 기준을 들고 스스로 비교하게 한다. 네 템플릿 6번에 들어 있다
  - 비포/애프터 사진 (화장품은 표시광고법 주의 — 개인차 문구 필수)
  - 시험성적서·인증서 캡처
  - 숫자 한 개 크게: "-4.9°C 쿨링", "425배 수분", "24시간 지속" (올리브영 1위 선케어들이 쓰는 방식)
- **숫자·비교 근거가 하나도 없으면 `.criteria` 표 하나로 세우거나 섹션을 뺀다.** 숫자를 억지로 만들면 거짓이 된다.

### 7. 사용 장면 (언제·어떻게)
- **역할:** 손님이 자기 일상에서 쓰는 모습을 상상하게 하기.
- **구성:** 장면 2~3개. "아침 출근 전 / 아이 간식 / 캠핑 갈 때" 식으로 상황 이름 + 사진.
- 사용법이 복잡하면 1-2-3 단계로.
- 식품은 **조리법·활용 레시피**, 뷰티는 **사용 순서(세안 후 → 패드 → 토너)**, 생활용품은 **설치/사용 3단계**.

### 8. 후기
- **역할:** 남이 대신 설득해주는 자리. 가장 강력한 섹션.
- **구성:** 실제 후기 3~5개. 핵심 문장만 뽑아 크게, 별점·날짜·구매옵션 표시. 사진 후기 있으면 최우선.
- 쿠팡 상위 전략: 베스트 리뷰 핵심 문장 + **판매자 답글**을 같이 보여주면 신뢰가 더 올라간다.
- **후기 없으면:** 8번 후기 블록을 지우고 `.fitcheck`("이런 분께 맞아요 / 이런 분껜 안 맞아요" 각 3개)로 대신한다 — 자리는 템플릿마다 다르다(연출형·정보설득형(`fit fitcheck`)·실사형 8번, 매거진형 10번 `.recommend` 대신). **"첫 후기 이벤트 — 사진 후기 남기면 ○○ 드려요"는 사은품이 실제로 있을 때만** 한 줄 덧붙인다(없는 사은품을 지어내지 않는다, 대가 제공 표기). 가짜 후기는 절대 금지(법 위반). 후기가 있으면 `.fitcheck`는 지운다.

### 9. 상세 정보
- **역할:** 꼼꼼한 손님용. 여기서 이탈하면 안 되니까 표로 깔끔하게.
- **구성:** 표 한 개. 사이즈/용량/구성품/소재·원재료/원산지/제조사/인증/유통기한·보관법.
- 식품은 **원재료·알레르기·영양정보**, 화장품은 **전성분·사용기한**, 생활용품은 **소재·KC인증·호환 규격**이 법적 필수.

### 10. 이런 분께 추천 + 자주 묻는 질문
- **역할:** 마지막 망설임 지우기.
- **추천:** 체크리스트 3~4개 ("□ 손이 자주 트는 분 □ 주방 냄새에 예민한 분"). 후기가 없으면 `.fitcheck`로 "안 맞는 분"까지 정직하게 — 안 맞는 경우를 먼저 말해 주면 나머지 말이 믿긴다.
- **FAQ:** 3~5개. Q5 고민 + 실제로 많이 들어올 질문(배송·사이즈·교환·보관). 접는 아코디언 금지 — 이미지로 올리면 안 열린다. 답까지 펼쳐서 보여준다.

### 11. 혜택 + 구매 유도 (지금 사야 하는 이유)
- **역할:** 결정. "나중에"를 "지금"으로.
- **구성:** 구성 + 사은품 + 기한/수량(진짜일 때만) + 마무리 문구 한 줄.
- **판매가는 넣지 않는다 (모든 카테고리 공통).** 플랫폼 가격 영역이 이미 보여주고, 할인·가격이 바뀔 때마다 이미지를 다시 만들어 올려야 한다. **사용자가 요청할 때만** 표기 — 그때는 정가 → 할인가 순서(진짜 정가만), 처음 보이는 가격이 총액. 도서 정가처럼 법적 필수 표기인 경우는 예외로 9번 상세 정보 표에 넣는다.
- **옵션 구성표는 조건부 (2026-11-21).** 스마트스토어·자사몰 + **고를 수 있는 옵션이 2개 이상**(수량 1봉/3봉/6봉, 색상, 세트 종류 — 한 세트 안 구성품 개수는 상관없다, 구성품은 구성 블록이 맡는다) + 사용자가 넣겠다고 하면 이 섹션에 "구성 / 용량·수량 / 추가금" 표(`.optable`). 판매가 총액 없이 추가금만. 쿠팡은 넣지 않는다. 규칙은 SKILL.md "가격".
- **CTA 버튼은 넣지 않는다 (사용자가 요구할 때만).** 플랫폼에 구매 버튼이 이미 있고, 이미지로 올린 가짜 버튼은 눌리지도 않는다. 대신 욕구가 해결된 장면 문구 한 줄로 마무리: "내일 아침, 책상 위에 ○○가 서 있을 거예요". "사라/구매하세요" 같은 직접 명령은 금지.
- **거짓 희소성 금지.** 재고가 있는데 "품절 임박"이라 쓰면 신뢰 잃고 법에도 걸린다.

### 12. 배송·교환·고지
- **역할:** 안심. 작게, 하지만 빠뜨리지 않기.
- **구성:** 배송 기간·비용, 교환/환불 기준, 문제 생겼을 때 처리 기간·연락처(SKILL.md Q6-1 답. 모르면 "플랫폼 기본 안내를 따릅니다" 한 줄), 법적 고지(식품·화장품은 "개인차가 있을 수 있습니다", 건강기능식품은 "질병의 예방 및 치료를 위한 의약품이 아닙니다").

## 카테고리별 변형

카테고리마다 손님이 궁금해하는 게 다르다. **`categories.md`를 읽고** 15개 카테고리(패션·뷰티·출산유아동·식품·주방·생활·홈인테리어·가전디지털·스포츠레저·자동차·도서·완구취미·문구·반려동물·헬스건강식품) 중 맞는 걸 골라 위 공통 구조에 덮어쓴다.
