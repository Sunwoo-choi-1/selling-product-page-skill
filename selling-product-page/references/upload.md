## HTML이냐 이미지냐 (2026-11-21 조사)

**결론: 쿠팡·스마트스토어는 이미지로 올리는 게 기본이고, HTML은 자사몰(카페24 등)에서만 그대로 쓴다.**
- 판매자 비율을 낸 공식 통계는 없다. 대신 정황이 한쪽으로 모인다:
  - 외주 상세페이지(크몽 등)와 규격 가이드가 전부 "가로 860(쿠팡 780) × 세로 ○○px **JPG**"로 납품·안내한다.
  - 스마트에디터 ONE에 HTML을 붙이면 원형 배지가 찌그러지고 둥근 모서리가 무시되고 비율 그래픽이 사라졌다는 셀러 실험이 있다. 에디터가 허용하는 CSS 목록은 공개돼 있지 않다.
  - 쿠팡도 앱·웹에 맞는 HTML 최적화가 까다롭다는 게 제작사 설명이다. 마켓 연동 솔루션(카페24 마켓플러스)은 스마트스토어에 "HTML 작성" 형태로만 보낸다 — HTML은 주로 연동 도구가 쓰는 길이다.
  - 출처: gpters 스마트에디터 ONE HTML 실험, 카페24 마켓플러스 안내, 쿠팡·스마트스토어 규격 가이드(1minutesangse·후커블·planning-s). 링크는 `research.md`.
- **초보 사장님 기준:** HTML·개발자도구·캡처를 만지게 하지 않는다. Claude가 `export_page.py`로 이미지를 뽑아 주고, 사장님은 이미지를 순서대로 올리기만 한다. `2_상세페이지.html`은 "원본"이고, 고칠 땐 Claude에게 말하면 이미지까지 다시 뽑는다.
- **이미지만 올릴 때의 약점 — 글이 안 읽힌다.** 검색·AI 요약이 이미지 속 글을 못 읽을 수 있다. 그래서 아래 "이미지로 올려도 글은 같이"를 꼭 한다. 이게 HTML의 장점을 대신한다.

## 업로드 이미지 뽑기 (Claude가 한다)
```
python assets/export_page.py 2_상세페이지.html 3_업로드이미지/ --platform smartstore|coupang|both|mall
```
- `mall` = 자사몰(카페24 등)만 쓸 때. 자사몰은 HTML을 그대로 넣는 게 기본이라 이 이미지는 미리보기·카톡 확인용(또는 이미지형 업로드용)이고, 스마트스토어 접힘 점검은 하지 않는다.
- 폰 화면(스마트스토어 430px · 쿠팡 390px)을 2배로 찍어 가로 860 / 780px. PC 레이아웃으로 찍으면 폰에서 글씨가 반으로 줄어 못 읽는다.
- 결과: 플랫폼 폴더(`스마트스토어/`·`쿠팡/`·`자사몰/`)마다 `상세_전체.jpg` 1장(통이미지) + `조각_01.jpg`…(섹션 경계에서 자름, 장당 3,000px 이하). 점검 보고서 `_export_report.json`은 **출력 폴더 최상단에 1개**(플랫폼별 결과가 그 안에 다 들어간다). 쿠팡은 옵션 구성표가 자동으로 빠진다.
- 페이지가 16,384px를 넘어도 끝까지 찍힌다(3,000 CSS px씩 나눠 찍어 이어 붙임). Windows 콘솔(cp949)에서도 안 죽는다.
- 어떤 걸 올리나:
  - **스마트스토어:** `상세_전체.jpg` 한 장이 제일 쉽다(장당 20MB, 세로 제한 없음). 에디터에서 사진 사이에 글을 끼우고 싶으면 조각으로.
  - **쿠팡:** 조각을 번호 순서대로(장당 세로 제한 — 자료마다 3,000~5,000px라 3,000px로 자른다, 장당 10MB, GIF 불가).
  - **폰으로 먼저 확인:** `상세_전체.jpg`를 카톡으로 보낸다(예전 `_한파일.html` 대신).
- 스크립트를 못 쓰는 환경이면(사장님 PC에 직접 안내해야 할 때만) 손으로: 크롬에서 `2_상세페이지.html` 열기 → F12 → 기기 모드 → 가로 430, "Add device pixel ratio" 2 → Ctrl+Shift+P → "Capture full size screenshot".

## 모션을 살리고 싶을 때 (선택)
HTML의 모션 2곳(첫 화면 등장·숫자 카운트업)은 캡처하면 사라진다. 살리려면:
- **스마트스토어**: GIF 허용. 브라우저 도구(Chrome MCP `gif_creator`)가 있으면 1번 섹션 로드 장면을 2~3초 GIF로 녹화 → `images/01_hook.gif`로 저장 → 에디터에 GIF 업로드. 없으면 ScreenToGif(무료) 같은 프로그램으로 화면 녹화.
- **쿠팡**: GIF 불가. 같은 장면을 mp4로 녹화해 "상품 상세 동영상" 기능에 올린다.
- **자사몰(카페24)**: HTML 그대로 올리면 모션이 그대로 산다. `<script>` 블록이 잘리는 에디터면 ②숫자 카운트업만 빠지고 ①은 CSS라 남는다.
- GIF는 5MB 넘기지 않는다(로딩). 폰에서 자동재생되는지 확인.

## 네이버 스마트스토어
- 가로 860px (공식 FAQ 권장은 848px — 860도 무방). 세로 제한 없음(장당 20MB).
- **상세 전체가 4,000px를 넘으면 앞 3,000px만 보이고 나머지는 "펼쳐보기"로 접힌다** (2026-11-20 확인). 규칙: **3번 섹션이 앞 3,000px(860폭 업로드 이미지 기준) 안에서 시작한다** = 1·2번 통째로 + 3번 제목 시작. `export_page.py`가 3번 시작 위치를 재서 넘으면 보고서에 적어 준다(그럼 1번 첫 화면·2번 신뢰를 줄인다).
- AI로 만든 이미지는 네이버 "AI 생성물 사용 기준"(2026-07-10)에 따라 표기한다 — 상세 안 `.cap` "연출 이미지(AI 활용)". 제한 카테고리는 표기 의무, 위반 시 미노출.
- 판매자센터 → 상품등록 → 상세설명 → "SmartEditor ONE" → 사진 추가 → `3_업로드이미지/스마트스토어/상세_전체.jpg` 한 장(또는 조각을 순서대로). 그 아래에 글 블록으로 상품명·장점 제목·상세정보 표·FAQ를 붙인다.
- 이미지마다 "대체 텍스트"에 상품 키워드를 넣는다 (검색 노출에 도움).
- 텍스트 일부는 에디터에 직접 타이핑하면 검색이 더 잘 된다 — 1번 헤드카피, 9번 상세정보 표는 텍스트로 넣는 걸 권장.
- 10장 이상 권장.

## 쿠팡
- 가로 780px, 세로 장당 3,000~5,000px(자료마다 다름 — 우리는 3,000px로 자른다), 장당 10MB 이하, **GIF 불가**.
- 상세 이미지에 할인·무료배송 같은 가격·프로모션 문구와 외부 URL을 넣지 않는다(쿠팡 상세 가이드, 2026-11-20 조사). 바뀌면 이미지를 다시 올려야 하고 심사에서 걸린다. 한 HTML에서 같이 뽑으므로 그런 문장에 `class="no-coupang"`을 붙인다 — `export_page.py`가 쿠팡 이미지에서만 빼고, 남은 문구는 보고서에 적는다.
- 대표(썸네일) 이미지는 1000×1000, 흰 배경, 상품만, 글자·합성 금지 — 안 지키면 광고 노출 제한.
- Wing → 상품등록 → 상세설명 → 이미지 업로드 → `3_업로드이미지/쿠팡/조각_01.jpg`부터 번호 순서대로.
- 쿠팡은 "신뢰 → 차별점 → 구매 유도" 순서가 잘 맞으니 2번 배지를 1번 바로 아래 붙여서 캡처.
- 공급처 이미지랑 똑같으면 아이템위너 경쟁에서 밀린다 — 반드시 자체 첫 화면을 쓴다.

## 카페24 자사몰 (다른 자사몰 솔루션도 같다)
- HTML로 넣을 수 있다. 단 **템플릿 원형 그대로는 붙이지 않는다.** 스킨 CSS가 상세설명 안까지 들어와서 ① 조상의 `text-align:center`가 상속돼 전부 가운데 정렬, ② `h2{color}` `p{margin}` `img{border}` 같은 요소 규칙이 새어 들고, ③ `word-break` 기본값이 없어 한국어가 글자 단위로 끊긴다.
- 그래서 `2_상세페이지.html`은 만들 때 이미 변환해 둔다(`scope_for_mall.py --standalone`). 올릴 땐 `python assets/scope_for_mall.py 2_상세페이지.html <임시경로>/몰에_붙일_부분.html --img-map <URL.json> --alt-prefix <브랜드>`로 `▼▲` 사이를 꺼내 이미지 URL을 바꾼 조각을 넣는다. 규칙은 SKILL.md "자사몰에 HTML로 넣을 때" 항. 손으로 할 때도 같은 세 가지: 모든 선택자를 래퍼 아래로 / 래퍼 본체에 `text-align:left; word-break:keep-all; overflow-wrap:break-word; line-height` 직접 지정 / 글자 속성은 전부 `!important`.
- 넣는 위치: 상품등록 → 상세설명 → "HTML" 모드 → 그 조각 전체(`<style>` + `<div class="pdp">…</div>`). Admin API(`description` 필드)로 넣으면 `<style>`이 그대로 저장된다(2026-10-29 확인). 에디봇이 `<style>`을 지우면 인라인 스타일 버전을 따로 만든다.
- 이미지는 카페24 "파일 업로더"나 별도 스토리지(GCS 등)에 먼저 올리고 `--img-map`으로 URL을 바꿔 넣는다.
- 올린 뒤 점검: 실제 상품 페이지를 PC와 모바일에서 열어 **본문이 왼쪽 정렬인지, 단어 중간이 끊기지 않는지, 한 줄 문장이 한 줄로 들어가는지** 본다. 프론트 캐시 때문에 저장 뒤 1~2분 지나야 바뀐다(예전 화면이 보이면 기다렸다 새로고침).
- 헤드리스 크롬으로 모바일 캡처를 뜰 때는 창 폭이 약 500px 아래로 안 내려간다. 430px짜리 `<iframe>`에 상품 페이지 URL을 넣은 로컬 HTML을 띄워서 찍는다(가로 500px 창 → iframe 430px). 그냥 `--window-size=430`으로 찍으면 오른쪽이 잘린 것처럼 보여 착각한다.

## 인스타그램 / 블로그

- 섹션 1·3·4·5(장점 3개)·8·11 순서로 카드화. 각 카드 = 이미지 + 큰 글씨 한 줄.
